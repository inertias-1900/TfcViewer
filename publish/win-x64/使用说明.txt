TFC 群系查看器（TfcViewerGui）
================================

一个 TFC（TerraFirmaCraft）离线世界群系查看器。无需 Java、无需游戏本体，
输入世界种子即可查看群系分布、温度、降水，并支持点击查询、多选群系高亮。

本工具完全由「什亭之匣」Vibe Coding 制作（引擎为 TFC 1.21 世界生成的
0 依赖 .NET 移植，已与 Java 游戏逻辑逐像素 100% 对拍一致）。

----------------
运行要求
----------------
- Windows 10/11 x64
- 需要 .NET 8 Desktop Runtime（若未安装，程序无法启动）：
  https://dotnet.microsoft.com/download/dotnet/8.0
  安装 "Windows Desktop Runtime 8.0.x - x64" 即可。

----------------
使用方法
----------------
启动：双击 TfcViewerGui.exe，或在命令行运行：
    TfcViewerGui.exe <种子>
种子支持数字（长整型），或字符串（按 Minecraft 规则取 Java hashCode，如 testseed2）。
窗口大小固定（不可拉伸）；应用图标为原版 MC 小麦（来自 Minecraft 资源）。

顶部工具条：
    种子          输入新种子后点"加载"（默认 testseed2 = -1162099057）
    中心 X / Z    当前视图中心（方块坐标），配合"跳转"或直接回车
    块/像素       每像素代表的方块数（默认 16 = 每像素 1 区块 = 512×512 chunk 视图；
                  缩小数值并跳转可看更精细的局部；也可用鼠标滚轮缩放）
    图层          （已由右侧「筛选模式」取代，见下节）

左侧图例：
    按右侧「筛选模式」列出当前视图内出现的分类，每项后面带占画面百分比：
      群系模式："中文名(tfc:xxx)"，中文名取自群峦官方中文翻译
      温度/降水/气候模式：分档名称（如 "温和 10~20"、"热带雨林气候"）
    点击可多选：未选中的分类全部灰度显示，选中的保持原色并加白色描边。
    图例标题旁出现"✕ 取消选择"按钮，点击清除全部选中。

右侧栏：
    上部为状态显示区：中心坐标、视图范围（块/km）、块/像素、当前筛选、渲染状态。
    中部为筛选模式：群系 / 温度 / 降水 / 气候。切换后会：①按该分类重涂地图
      ②重刷左侧图例 ③改变点击高亮的分类口径。
      温度/降水/气候三档按海平面 y=63 计算（升高 10 格约降 1.6 ℃）。
    下部为整体预览：白色边框标记当前视图范围，**左键点击或按住拖动**即把该点
      设为主画面中心。

主画布（512×512 像素，默认显示 512×512 区块范围）：
    单击任意位置弹出详细信息气泡，包含：区块坐标、方块坐标、预测群系、
      基础温度、年温范围（最低~最高）、年均温与年温差、降水、
      预测群系类型（世界生成选群系的阈值线）、气候分类（柯本）、
      冬季表现（会结冰 / 会积雪 / 不会结冰）、置信度
    左右两侧有**纬度刻度**小字（TFC 纬度轴：z=0 赤道，|z|=10000 格为 90°）。
    鼠标滚轮：以鼠标位置为中心缩放。
    渲染进行中主画布会显示灰白覆盖层与"正在重新计算"提示。

----------------
温度口径（季节气候）
----------------
查看器显示的温度是"游戏内会实际出现的温度范围"，不是世界生成阶段的单一温度值：
- 基础温度：来自地形生成的 128×128 格气候网格，按 TFC ChunkData 的方式做四角
  双线性插值（这才是游戏内的取值口径；旧版直接取格点值会有偏差）。
- 年最低温 / 年最高温：把 TFC 的季节摆动（月份修正 -1 ~ +1，作用在纬度项
  12~18 ℃ 上）、每日随机偏移（±3 ℃，按天数取种子）、日内变化（±0.9 ℃）
  在整年逐小时扫一遍取极值，再加海拔修正（海平面 63 以上每格 -0.16225 ℃，
  封顶 17.822 ℃）。
- 年均温：全年逐小时温度的平均值 = 基础温度 + 海拔修正（季节项相互抵消）。
- 图层与气泡默认按 y=63（海平面）计算；海拔越高越冷，每升高 10 格约降 1.6 ℃。
  需要用其他高度核对时，可用命令行 --y=<高度> 参数（见下）。
- 该口径与时刻无关：不需要选择日期，也不用启动游戏。
- 与游戏对照：在游戏内读某点温度，同一位置同一时刻应落在给出的年范围内
  （夏季接近年最高，冬季接近年最低）。

----------------
字段说明
----------------
- 预测气候：按 TFC 游戏真实选择阈值分类：
    冰盖（温度 < -17+0.006×降水）
    冰缘（< 冰盖线+2.5）    古冰缘（< 冰盖线+6）
    沙漠（降水 < 60）       半干旱（降水 60~155）
    半湿润（降水 250~375）  湿润（降水 > 375）
    湿热（降水 >425 且 降水+10×温度 >500）
    温带（其余）
- 置信度：该位置周围约 20×20 方块范围内与中心同群系的比例（启发式指标，
  用于识别群系过渡带；世界生成本身是确定性的）。
  置信度低于 100% 的情形：群系交界/过渡带、海岸线附近、河流周围（fractal
  缓冲带覆盖多个群系）、高缩放（单像素代表 16×16 块以上跨混合区域）、以及
  喀斯特系（cenote/doline/石林）等小尺度交错群系。需要精确定位时缩小
  "块/像素"数值后重新点击。

----------------
重新构建（可选）
----------------
需要 .NET 8 SDK。
    GUI（查看器）：cd gui && dotnet publish -c Release -r win-x64
    CLI（命令行出图）：dotnet build -c Release 后运行 bin/Release/net8.0/tfcviewer
        tfcviewer <种子> [大小=512 chunk] [块每像素=16] [图层] [输出.png]
        图层: biome | temp_mean(年均温) | temp_min(年最低) | temp_max(年最高) | rainfall
        单点查询（含年温范围）：
        tfcviewer --info <种子> <x> <z> [--y=63] [--days=8]
        tfcviewer --info x <x> <z> --save=<存档目录>   （直接读存档的种子与日历）
        自洽验证：tfcviewer --selftest [种子] [每月天数]
