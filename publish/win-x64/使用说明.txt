TFC 群系查看器（TfcViewerGui）
================================

一个 TFC（TerraFirmaCraft）离线世界群系查看器。无需 Java、无需游戏本体，
输入世界种子即可查看群系分布、温度、降水，并支持点击查询详细信息。

本工具完全由「什亭之匣」Vibe Coding 制作（引擎为 TFC 1.21 世界生成的
0 依赖 .NET 移植，已与 Java 游戏逻辑逐像素 100% 对拍一致）。

----------------
运行要求
----------------
- Windows 10/11 x64
- 需要 .NET 8 Desktop Runtime（若未安装，程序无法启动）：
  https://dotnet.microsoft.com/download/dotnet/8.0
  安装 "Windows Desktop Runtime 8.0.x - x64" 即可。

----------------
使用方法
----------------
启动：双击 TfcViewerGui.exe，或在命令行运行：
    TfcViewerGui.exe <种子>
种子支持数字（长整型），或字符串（按 Minecraft 规则取 Java hashCode，如 testseed2）。

顶部工具条：
    种子          输入新种子后点"加载"（默认 testseed2 = -1162099057）
    中心 X / Z    当前视图中心（方块坐标），配合"跳转"或直接回车
    块/像素       缩放级别（16 = 每像素 1 个区块；越小越精细；也可用鼠标滚轮缩放）
    图层          群系 / 温度 / 降雨 切换

左侧图例：
    列出当前视图内出现的所有群系（色块 + 名称）。
    点击可多选群系；选中后主画布中未选中的群系全部灰度显示，
    选中的群系保持原色并加白色描边高亮。
    图例标题旁出现"✕ 取消选择"按钮，点击清除全部选中。
    （仅"群系"图层显示图例）

主画布：
    默认"查看"模式：单击任意位置弹出详细信息气泡，包含：
        区块坐标 (chunkX, chunkZ)、方块坐标、预测群系、温度、降水、预测气候、置信度
    勾选右下角"拖动模式"后：按住左键拖动平移视图；画布显示黄色边框提示。
    鼠标滚轮：以鼠标位置为中心缩放。

右下角整体预览：
    显示 8 倍于主视图跨度的大地图；白色边框矩形标记当前视图范围。
    点击或按住拖动预览图可快速跳转；"拖动模式"按钮位于其上方。

----------------
字段说明
----------------
- 预测气候：按 TFC 游戏真实选择阈值分类：
    冰盖（温度 < -17+0.006×降水）
    冰缘（< 冰盖线+2.5）    古冰缘（< 冰盖线+6）
    沙漠（降水 < 60）       半干旱（降水 60~155）
    半湿润（降水 250~375）  湿润（降水 > 375）
    湿热（降水 >425 且 降水+10×温度 >500）
    温带（其余）
- 置信度：该位置周围约 20×20 方块范围内与中心同群系的比例（启发式指标，
  用于识别群系过渡带；世界生成本身是确定性的）。

----------------
已知说明
----------------
- 首次渲染约 1~4 秒（视窗口大小）；拖动/缩放后自动重渲染。
- 引擎为离线复刻，与游戏内实际生成 100% 一致（已对拍两个种子 512×512 全图 0 差异）。

----------------
重新构建（可选）
----------------
需要 .NET 8 SDK。
    GUI（查看器）：cd gui && dotnet publish -c Release -r win-x64
    CLI（命令行出图）：dotnet build -c Release 后运行 bin/Release/net8.0/tfcviewer
        tfcviewer <种子> [大小=512 chunk] [块每像素=16] [图层] [输出.png]
